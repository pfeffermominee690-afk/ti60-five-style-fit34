# 外壳实物与机械设计

两套外壳均由团队自主建模并采用 3D 打印制作。第一套将摄像头与屏幕布置在同侧；第二套将摄像头与屏幕分置两面。外壳使用 ABS、PLA Basic、PETG 等材料，整机由充电宝供电。

全部 16 张图片保留原始内容，点击可查看原图。
